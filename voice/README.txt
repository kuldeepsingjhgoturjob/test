VOICE FILES (optional): make the website voice sound like a real person
====================================================================
The website plays a recorded voice if these files exist in this folder.
If a file is missing, it uses the visitor's phone/laptop voice instead.

How to make them:
  - Record each line on your phone in a quiet room, in a calm, warm, low voice, OR
  - generate it with a natural-sounding voice tool (choose a calm, low-pitched voice).
  - Save as MP3, keep each file under 1 MB, and use EXACTLY these file names.

Put the files in this folder (voice/) and deploy again. Nothing else to change.
